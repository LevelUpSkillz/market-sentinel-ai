# 0.7.1 — Graphite Edition

Prepared; production verification pending.

User finds cyan/violet neon too AI-generated. New direction: warm graphite,
mineral white, muted copper, sage up/buy/healthy states and terracotta down/sell/
problem states. Recolored the full existing stylesheet cascade, canvas/SVG charts,
icon and browser theme. Restrained flat surfaces, no chromatic heading gradient,
less bloom, quieter background and crisp borders retain the actual interactive
3D/radar graphics across the app. Fewer per-level depth labels prevent crowding
on a small screen; complete values remain available in the existing inspector.

No data/model/provider/AI/account/order/auth/backend/collector/vault/hosting-plan
change. Existing market freshness, explicit manual trade approval, source labels,
mobile controls, rotation, FX and reduced-motion behavior remain.
